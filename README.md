# Chuloshots

Portfolio website for **Samuel Anthony**, professionally known as **Chulo**, a creative video editor for YouTubers, content creators and brands.

**Live site:** [chuloshots.vercel.app](https://chuloshots.vercel.app)

## What's on the site

- An opening section with a cut-out portrait and a moving dot-grid background
- **My work:** glass folders that open to play the edits in a full-screen player
- Packages and pricing, the editing toolkit, and contact links (WhatsApp, Instagram, email)

## Built with

Next.js (App Router, static export), TypeScript, Tailwind CSS and shadcn/ui. Hosted on Vercel.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. `npm run build` writes the static site to `out/`.
